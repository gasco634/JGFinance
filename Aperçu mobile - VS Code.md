# Aperçu mobile dans VS Code

1. Ouvre ce dossier comme workspace dans VS Code.
2. Dans **Run and Debug**, choisis **Bilan Financier · émulateur mobile** puis appuie sur **F5**.
3. Sélectionne un format, passe en paysage ou actualise depuis la barre de l’émulateur.

L’aperçu affiche l’application réelle dans un viewport de téléphone. Les réglages VS Code lancent un serveur local et le navigateur intégré. VS Code peut proposer l’extension Microsoft **Live Preview** pour les aperçus avec rafraîchissement automatique.

La première ouverture sur `127.0.0.1` utilise un espace local de navigateur distinct de l’ouverture directe du fichier HTML. Crée un compte dans cet aperçu ; cela ne remplace pas les données locales de l’autre origine.
