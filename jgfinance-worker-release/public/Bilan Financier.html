      VOTRE ESPACE

      Réglages

      Adaptez JGFinance à votre pays, votre devise et vos habitudes.

      Région et devise

      Choisissez la monnaie dans laquelle vous saisissez vos opérations et consultez vos bilans.

      Exemples : XOF pour le Burkina Faso, USD pour les États-Unis, EUR pour la zone euro. Tout code de devise ISO reconnu peut être saisi.

      Choisissez vos couleurs

      Trois ambiances lisibles, du thème JGFinance aux palettes océan et forêt.

      Installer JGFinance sur votre téléphone

      Sur iPhone, ouvrez cette application dans Safari, touchez Partager, puis Sur l’écran d’accueil. Sur Android, ouvrez le menu du navigateur et choisissez Installer l’application ou Ajouter à l’écran d’accueil. L’installation est disponible quand JGFinance est hébergée sur une adresse HTTPS.

      Sauvegarde entre appareils

      Sauvegarde cloud en attente
      Vos données sont conservées sur cet appareil jusqu’à la configuration du projet Supabase JGFinance.
